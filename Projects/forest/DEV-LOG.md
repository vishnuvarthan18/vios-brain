# DEV-LOG: Sathyamangalam Atlas (forest)

Coding history from Claude Code sessions on the personal Mac. Repo: vishnuvarthan18/sathyamangalam-atlas (local ~/sathyamangalam-atlas). Main page: [[Projects/forest/SUMMARY]]

## What was built
- **The Sathyamangalam Record** — an open, cited reference site for the Sathyamangalam landscape (tiger reserve, people, history, species).
  - `data/atlas.db` (SQLite) is the single source of truth. `exports/*.json` are generated by `make export` (scripts/export_from_db.py). `data/curated/` holds hand-written species, places and bibliography.
  - Static site in `site/` (home, land, life, people, history, record, about, credits...). Built to `dist/` and hosted on Cloudflare Pages: production sathyamangalam.online, dev site dev.sathyamangalam.online (Pages project sathyamangalam-atlas-dev, branch dev).
  - Generated detail pages: 2,664 species pages (/life/<category>/<slug>), 92 place pages (/land/<slug>), 83 history pages (/history/<slug>).
- **Harvest engine** (`harvest-engine/`) — separate Cloudflare Worker that pulls data from ~29 sources (GBIF, iNaturalist, CrossRef, Europe PMC, Unpaywall, OpenAlex, Wikidata, LGD/data.gov.in, NTCA, WII, Shodhganga, FIRMS, GEE, news sites...) into D1 + R2 with provenance. Cron 3x a day, Queues, password-protected dashboard at engine.sathyamangalam.online. Built as a template: a second reserve is one more row in the `reserve` table.
  - Sensitive-species rule: exact locations of sensitive species are coarsened (~5 km) for public use; registry in `sources/sensitive-species.json` (now 17 species).
- **D1 to atlas.db sync** — `scripts/sync_d1_to_atlas.py` (built 2026-09-06), with a provenance table; idempotent.
- **Worldwide comparables library + pitch page** — 585 comparable projects (from the 25 Aug 2026 research) as a searchable HTML page, plus a one-page "Forest and Wildlife Atlas" overview, merged into one shareable file `docs/share/forest-and-wildlife-atlas.html`.
