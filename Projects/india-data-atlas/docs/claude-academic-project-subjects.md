# Academic subjects the platform supports (researched 2026-09-21)

Visual page: https://claude.ai/artifact/K1w2So9CW4x12GYUzi68vc

Best pick: **Geoinformatics**. Indian M.Sc Geoinformatics syllabi (Adamas, Centurion, SGBAU) cover spatial databases, web GIS, remote sensing and a final project.

| Subject | Project idea | Data we already have | Ready |
|---|---|---|---|
| Geoinformatics / Tourism | AHP+GIS ecotourism site suitability across protected areas | PAs, peaks, species, water | ~85% |
| Remote sensing | Forest change inside vs outside protected areas | FSI, WorldCover, PA shapes | ~80% |
| Biodiversity informatics | Bias in GBIF India data (92% eBird) and where records are missing | GBIF, WCVP | ~80% |
| Anthropology / Human geography | ST population vs forest cover by district | Census ST (585 districts), FSI | ~75% |
| Linguistics | Language diversity map | 830 Glottolog languages | ~70% |
| Geoinformatics / Data quality | OSM vs WDPA boundaries (no India-wide published study found, so it's a research gap) | OSM live; WDPA needs key | ~60% |
| Hydrology | GIS prediction of spring zones (springs are a data gap) | NWDP 624 | ~45% |
| Environmental law | Quality of FRA title reporting | J&K only | ~35% |
| Computer science | A data platform that tracks where every fact comes from | Whole system | ~95% |

Each has published web proof (links are on the page).
