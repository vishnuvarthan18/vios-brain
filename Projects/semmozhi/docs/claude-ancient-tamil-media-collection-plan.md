# Ancient Tamil Writing Surfaces: Collection Plan

Saved: 2026-09-25. Purpose: collect images, facts and vectors for every surface Tamil was written on, to drive the site redesign. Replaces the palm-leaf-only scope in `claude/ollai-chuvadi-reference-catalog.md` (that catalog remains the palm-leaf section).

## Scope: 7 surfaces

1. Palm leaf (ஓலைச்சுவடி): literature, medical texts. Catalog already started.
2. Stone: cave Tamil-Brahmi, hero stones (நடுகல்), temple-wall inscriptions.
3. Copper plate (செப்பேடு): royal grants, e.g. Chola Leiden plates, Pandya Velvikudi plates.
4. Pottery sherds: graffiti and Tamil-Brahmi on sherds (Keeladi, Arikamedu, Adichanallur, Kodumanal, Porunthal). Names and dates to be verified per site.
5. Coins: Sangam-era Chera, Chola, Pandya coins, Roman coins found in Tamil Nadu, later dynasty coins.
6. Rings: signet and inscribed rings.
7. Seals: seals on copper plates, intaglios and clay seals.

## Per-asset record (one row each)

id, surface, object name, site or museum, date range (with source), script (Tamil-Brahmi, Vatteluttu, Grantha, Tamil), text transcription and meaning, image source URL, license, author/credit, resolution, file name, redraw needed (yes/no), notes.

## Phases

1. Rights rules (day 1). Allowed for shipping: public domain, CC0, CC-BY. Allowed for reference only: CC-BY-NC (e.g. CICT), unclear licenses, stock sites. Shipped visuals should be our own redrawn SVG wherever possible. The ancient objects are not copyrighted; museum photographs may be.
2. Source mapping per surface. For each, list 3 to 5 named sources and check license. Candidate types (each must be verified before use): Wikimedia Commons categories; museum open-access programmes (Met, British Museum, Rijksmuseum, Smithsonian, American Numismatic Society); Tamil Nadu State Department of Archaeology publications and Keeladi reports; ASI; Government Museum Chennai; Leiden University for the Leiden plates; Internet Archive for old South Indian Inscriptions volumes; Tamil Virtual Academy inscription pages.
3. Collection. Use the browser on the user's computer to view pages, log each candidate in the record sheet with its license. Real photos the user saves go into one folder per surface. Cloud downloads are blocked for most image hosts, and Wikimedia Commons is off-limits for this assistant, so the user saves Commons files.
4. Visual study. For each surface, write a spec from real photos: material colour, texture, script size and carving/scratch style, object proportions.
5. Redraw. Produce original SVG assets per surface: leaf strip and bundle, stone slab with carved lines, copper plate with ring and seal, sherd with graffiti, coin, ring, seal.
6. Design system. Tokens per surface (palette, texture, script treatment) and a mapping from surface to site section.

## Proposed surface-to-section mapping (to confirm with user)

- Stone and pottery: earliest script, Sangam era, origins.
- Palm leaf: literature reader (Thirukkural etc.).
- Copper plate and seals: kings, grants, administration.
- Temple-wall stone: Chola section (build first).
- Coins, rings: trade and daily life (Roman contact, Muziris, Arikamedu).
