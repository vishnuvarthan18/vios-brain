# Optimal Font Sizes for 430px Mobile Screens

## Chat

**Vishnu:** what are the font size will be suit for mobile screen 430px

**Claude:** For a 430px wide mobile screen, here are the recommended font sizes:

**Body Text:**
- 16px minimum (never go below this for readability)
- 16-18px is ideal for most content

**Headings:**
- H1: 24-32px
- H2: 20-24px
- H3: 18-20px
- H4: 16-18px

**Other Elements:**
- Small text/captions: 14px (use sparingly)
- Buttons: 16-18px
- Navigation: 16px

**Key Guidelines:**
- Use relative units like `rem` or `em` instead of `px` for better scalability
- Maintain good contrast ratios (at least 4.5:1 for normal text)
- Test with actual devices since pixel density varies
- Consider line-height of 1.4-1.6 for better readability
- Leave adequate spacing between text elements

The 16px minimum is crucial because anything smaller becomes difficult to read on mobile devices, and iOS Safari actually zooms in automatically if text is smaller than 16px, which can break your layout.
