Level: **Absolute beginner — pre-fundamentals**

What you have:

- Product-level understanding: dev/staging/prod, deploy + maintain, Git flow (push/pull/merge/PR) at a conceptual level
- Terminal exposure (used Claude Code in terminal)

Gaps identified:
- No hands-on HTML/CSS
- Function vs. conditional logic (if/else) not yet distinguished

- No programming fundamentals (variables, data types, control flow)

## Goal
Not "become a professional developer." Target: read and understand code well enough to debug, review, and direct AI coding tools with precision — instead of blindly trusting vibe-coded output. This will naturally require writing real code yourself, so expect it to pull you toward building small things unassisted within a few months. Job-ready dev is explicitly NOT the current goal.

## Time budget
Software is priority #1 of 4 domains sharing 7–10 hrs/week total. Suggested initial allocation: ~4–5 hrs/week to software while it's the active focus, tapering as electronics starts.

## Roadmap

### Phase 1 — Programming fundamentals (start here)
- Variables, data types (string, number, boolean, array, object)
- Conditionals (if/else) — you already grasp this intuitively, formalize it
- Loops (for, while) — your current gap
- Functions — properly distinguished from conditionals
- Practice in plain JavaScript (pairs naturally with your web/UI world)

### Phase 2 — How the web actually works
- HTML/CSS by hand (no framework) — build 2-3 static pages yourself
- What a browser does, what a request/response is
- Frontend vs backend vs database, correctly understood (backend = logic layer, not storage)
- What an API actually is (contract between systems, not just "a key")

### Phase 3 — Reading real code
- Take an existing AI-generated project you've vibe-coded — read it line by line, annotate what each part does
- Basic debugging: reading error messages, console.log, browser devtools
- Git properly hands-on: not just push/pull, but branches, resolving conflicts, reading a diff

### Phase 4 — Build small, unassisted
- Rebuild one small feature you've previously vibe-coded, from scratch, without AI writing the code
- Gradually reintroduce AI as a pair-programmer instead of sole author
