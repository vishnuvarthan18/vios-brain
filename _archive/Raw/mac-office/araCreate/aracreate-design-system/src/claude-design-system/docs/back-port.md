# BACK-PORT — retired

This file described what to carry from this project back into the repository's
`src/` when the repository was the master. On 24 August 2026 the direction was
settled the other way: **this project is the master and the repository is its
export.** There is nothing to back-port; the whole tree goes out.

Procedure and delete list: [`export/EXPORT.md`](export/EXPORT.md). Record of
each export: [`../github.md`](../github.md).

Of the eleven items the old checklist listed, all are done here — the dark theme
(`tokens/theme-dark.css`), density (`tokens/density.css`), the 14px link size,
the widened checkbox selector, the hoisted `--ac-chevron-size`, the tint-headroom
note — and reach the repository with the next export. The two Playwright gate
extensions it asked for belong to the repository's own `tests/` and are still
open there.
