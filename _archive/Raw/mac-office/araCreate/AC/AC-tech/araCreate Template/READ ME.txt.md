araCreate — the Duotint template
================================

TO OPEN IT
----------

Double-click:   Start website

A black window opens, then your browser shows the site.
Keep the black window open while you're looking at it.
Close that window when you're finished — that switches it off.

IMPORTANT: always open it with "Start website".
Do NOT double-click index.html — you'll get a list of files
instead of the website. The menu links need the black window
running to work.


IT IS A PHOTOCOPY
-----------------

This is a copy of the site as it was on 19 August 2026.

If you change something in Webflow later, this copy will NOT
change. It still shows the old version.

To make a fresh copy:

  1. Open the folder "araCreate Website"
  2. Open "Rebuild tools" inside it
  3. Double-click "Get the template"
  4. Wait a few minutes
  5. A new folder appears with the up-to-date copy

You only need to do that after changing something in Webflow.
Otherwise this copy stays correct.
