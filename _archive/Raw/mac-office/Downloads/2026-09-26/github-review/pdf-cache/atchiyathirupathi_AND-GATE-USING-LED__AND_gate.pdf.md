Simple AND Gate Circuit Using LEDs and Push Buttons

1. Introduction

The AND Gate Circuit is a basic digital logic circuit that demonstrates the principle of an
AND logic gate. The circuit uses LEDs as output indicators and push buttons as inputs. The
LEDs indicate whether the required input conditions are satisfied.

2. Objective

To understand the basic operation of an AND gate.
To learn how inputs control an output.
To demonstrate digital logic using simple electronic components.
To understand the use of LEDs as output indicators.

4. Working Principle

An AND gate produces an output only when all of its inputs are HIGH/ON.
For two inputs, A and B:




INPUT A                       INPUT B                       OUTPUT

OFF                           OFF                           OFF

OFF                           ON                            OFF

ON                            OFF                           OFF

ON                            ON                            ON
5. Circuit Operation

The battery supplies power to the circuit.
The two push buttons provide the two inputs.
Both inputs must be activated to produce the output.
When both buttons are pressed, the output LED glows.
If either button is released, the output LED turns OFF.
The resistors are used to limit current and protect the LEDs.

The AND-gate circuit was successfully constructed. The output LED glows only when both
input push buttons are pressed simultaneously, demonstrating the basic operation of an

7. Conclusion

This project provides a simple and practical demonstration of AND logic using LEDs, push
buttons, resistors, and a battery. It helps us understand how digital logic gates work and how
multiple inputs can control a single output.
