DUAL LED BLINKING AND CONTROL
SYSTEM USING ARDUINO UNO
1. Aim
To design and implement a simple dual LED blinking and control system using Arduino UNO,
where two LEDs are programmed to turn ON and OFF at regular time intervals.

2. Problem Statement
In basic electronic systems, controlling and switching multiple LEDs is an important
fundamental operation. Manually controlling LEDs can be inconvenient and does not
demonstrate automated digital control.

Therefore, an Arduino UNO is used to control two LEDs through programmed digital output
signals, allowing them to blink automatically at a fixed time interval.


3. Proposed Solution
The proposed system uses an Arduino UNO to control two LEDs connected to digital output
pins.
The Arduino sends HIGH and LOW signals to the LEDs. When the output is HIGH, the
corresponding LED turns ON, and when the output is LOW, it turns OFF. A programmed time
delay controls the blinking interval.
This project demonstrates the basic concepts of digital output control, LED operation, timing,
and Arduino programming.


4. Components Required
   1. Arduino UNO
   2. Two LEDs
   3. Breadboard
   4. Jumper Wires
   5. USB Cable



5. Circuit Working
The circuit consists of two LEDs connected to the digital output pins of the Arduino UNO
through current-limiting resistors.
The Arduino is programmed to control the ON and OFF states of both LEDs. The digital pins
provide HIGH and LOW signals to operate the LEDs.
When the output signal is HIGH, the corresponding LED turns ON. When the output signal is
LOW, the LED turns OFF.
Working Sequence
Both LEDs turn ON simultaneously.
After a fixed time delay, both LEDs turn OFF.
The process repeats continuously, producing a blinking effect.


6. Procedure
1.Connect the Arduino UNO to the breadboard using jumper wires.
2.Connect the first LED to digital pin 7 through a 220 Ω resistor.
3.Connect the second LED to digital pin 4 through a 220 Ω resistor.
4.Connect the cathode of each LED to GND.
5.Connect the Arduino UNO to the computer using a USB cable.
6.Upload the Arduino program to the UNO.
7.Check all connections carefully before powering the circuit.
8.Power the Arduino UNO.
9.Observe both LEDs turning ON and OFF according to the programmed time delay.
10.Verify that the blinking operation repeats continuously.



7. Applications
1. Indicator Systems – Used for visual indication of system status.
2.Embedded Systems – Demonstrates basic digital output control.
3.Electronic Prototyping – Useful for testing LED control circuits.
4.Educational Projects – Helps understand Arduino programming and digital signals.
5.Warning and Signaling Systems – LEDs can be used for basic visual alerts.

9. Result

The Dual LED Blinking and Control System using Arduino UNO was successfully
implemented. Both LEDs were controlled using digital output pins and blinked ON and OFF
