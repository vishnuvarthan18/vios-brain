LED Brightness Control Using Potentiometer
1. Aim

To design and implement a simple LED brightness control circuit using a potentiometer, LED,
resistor, battery, and breadboard, allowing the user to manually adjust the intensity of the
LED.

2. Problem Statement

In many electronic devices, controlling the brightness of LEDs is important for power saving,
user comfort, and visual indication. A fixed resistor provides constant brightness and does
not allow adjustment according to user requirements. Therefore, a simple and low-cost
method is needed to vary LED brightness efficiently.

3. Proposed Solution

The proposed system uses a potentiometer as a variable resistor to control the current
flowing through an LED. By rotating the potentiometer knob, the resistance changes, which
directly affects the current supplied to the LED. As a result, the LED brightness can be
increased or decreased smoothly.

4. Components Required

   ●​   LED (Light Emitting Diode)
   ●​   Potentiometer
   ●​   Resistor
   ●​   Breadboard
   ●​   9V Battery
   ●​   Battery Connector
   ●​   Jumper Wires

5. Circuit Working

   ●​ The circuit consists of an LED connected in series with a resistor and a
      potentiometer.
   ●​ The resistor limits the current and protects the LED from damage.
   ●​ The potentiometer acts as a variable resistor.
   ●​ When the potentiometer resistance is increased, the current flowing through the LED
      decreases, causing the LED to become dimmer.
   ●​ When the potentiometer resistance is decreased, more current flows through the
      LED, making it brighter.
   ●​ Thus, the brightness of the LED can be adjusted continuously by rotating the
      potentiometer knob.

6. Procedure
   ●​   Place the LED, resistor, and potentiometer on the breadboard.
   ●​   Connect the resistor in series with the LED.
   ●​   Connect the potentiometer in the circuit to control current flow.
   ●​   Connect the positive terminal of the 9V battery to the circuit.
   ●​   Connect the negative terminal to the ground rail.
   ●​   Verify all connections carefully.
   ●​   Power ON the circuit.
   ●​   Rotate the potentiometer slowly.
   ●​   Observe the change in LED brightness.
