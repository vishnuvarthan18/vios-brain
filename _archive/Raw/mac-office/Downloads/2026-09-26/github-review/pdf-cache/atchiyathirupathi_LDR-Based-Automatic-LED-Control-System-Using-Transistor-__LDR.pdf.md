LDR-Based Automatic LED Control
System Using Transistor

1. Aim
To design and implement an automatic LED control circuit using an LDR and transistor,
where the LED responds automatically to changes in the surrounding light intensity.



2. Problem Statement
Manual operation of lights requires continuous human attention and may result in the light
being unnecessarily switched ON or OFF. A simple sensing circuit is therefore required to
detect changes in light intensity and automatically control an LED.



3. Proposed Solution
The proposed project uses an LDR as a light sensor and a transistor as an electronic switch.
When the light falling on the LDR changes, its resistance changes accordingly. This
produces a change in the transistor's biasing condition, which controls the LED.

Thus, the system provides automatic light-dependent switching without manual control.

5. Circuit Working
The circuit consists of an LDR, transistor, resistor and LED connected to a DC battery

.When light intensity changes:

1. The LDR senses the surrounding light.

2. The resistance of the LDR changes according to the light intensity.

3. This changes the voltage/current applied to the transistor.

4. The transistor operates as a switch.

5. The transistor controls the current flowing through the LED.

6. Therefore, the LED automatically changes its ON/OFF state according to the LDR
condition.



Basic principle:
> Change in light → Change in LDR resistance → Transistor switching → LED output

6. Procedure
1. Place the LDR, transistor, LED and resistor on the breadboard.
2. Connect the components according to the circuit configuration.

3. Connect the battery as the DC power source.

4. Connect the LDR to the transistor's control/biasing section.

5. Connect the LED and its current-limiting resistor to the transistor output.

6. Check all connections carefully.

7. Switch ON the battery supply.

8. Expose the LDR to light and observe the LED.

9. Cover the LDR or reduce the surrounding light.

10. Observe the change in the LED output.
