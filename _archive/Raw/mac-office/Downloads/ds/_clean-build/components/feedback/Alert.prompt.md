Use for something on the page that stays put.

```jsx
<Alert tone="warning" title="Four places left">Apply before the cohort fills.</Alert>
<Alert tone="error" live="assertive" title="That email address is missing an @" />
```

Four tones and only two added colours: warning reuses the brand gold, information is charcoal. Resist a fifth. Use `live="assertive"` only for an error that blocks progress.
