# UI kit — araCreate Academy

araCreate Academy is one of the group's own properties and an intended consumer
of this system. This kit is a click-through recreation of its course-marketing
surface, built from the same components as the group website — the Academy has
no separate visual identity, and giving it one would be an invention.

| Screen | File | Shows |
| --- | --- | --- |
| Courses | `CoursesScreen.jsx` | split hero, stat row, marquee, course cards with price footers, dark steps band, fee cards, FAQ accordion |
| Tutors | `TutorsScreen.jsx` | person cards, duotint hero image, timetable table, testimonial |
| Apply | `ApplyScreen.jsx` | the full application form with live email validation, alerts, toast |

**Deliberately blank.** Course fees, tutor names other than the founder, and
student testimonials are visible placeholders — `00+`, `Tutor name`,
`Student name`. The Academy's real fee structure and cohort dates were not in
the sources.
