# WIKI

Reference notes that are **not** conventions.

The distinction matters. A convention is a rule — following it is not optional, and breaking it is a thing to fix. What is in this folder is context: choices that were made, how things currently are, what is worth knowing before starting. Useful, but not binding.

Keeping the two apart is what stops the conventions from bloating. A tool preference written into [`repo/`](../repo/) becomes a rule nobody agreed to; the same note here is just information.
