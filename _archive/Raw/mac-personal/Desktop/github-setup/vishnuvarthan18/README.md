# Vishnu Varthan

I design products and then build them.

I work on the shape of a thing before the stack — what it should do, who it is
for, and what to leave out. Mostly web and application software, with data and
ML work where the problem calls for it.

Most of what I build is private. What is here is the shared groundwork: the
conventions every repo of mine follows, and the scaffold new ones start from.

## Stack

| Layer | Tools |
| --- | --- |
| Design | Figma, prototyping in code where a static mock would lie |
| Web | TypeScript, Next.js, React, Tailwind |
| Backend | Node, PostgreSQL |
| Data | Python, pandas, scikit-learn, Jupyter |
| Tooling | Make, GitHub Actions, semantic-release |
