# SRC

Project source. Nothing else — data, notebooks, build output and shipped
artefacts each have their own folder at the root.

Pick the layout that matches this project and delete this file once the folder
has real contents:

- **Web and application software** — `app/ components/ lib/ hooks/ types/`
- **Data, ML and research** — `data/ features/ models/ pipelines/ viz/ config/`

The full layouts, and the rules about what may import what, are in the
[conventions](https://github.com/vishnuvarthan18/conventions/blob/main/repo/readme.md#22-src-by-project-type).
