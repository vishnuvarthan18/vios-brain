## 2. STO-070 / STO-071

Two Commons files whose titles differ only in letter case:

- `STO-070  stone/Brihadeeswarar_Temple_Stone_writings.jpg`
- `STO-071  stone/Brihadeeswarar_Temple_stone_writings.jpg`

macOS paths are case-insensitive, so both rows resolve to the **one** file that exists on
disk (`Brihadeeswarar_Temple_Stone_writings.jpg`). refs.db records the **same sha256**
(`33509d9e791d...`) for both rows, so the second download overwrote the first: there is one
image here, not two. Both are CC BY-SA 4.0 / STUDY, so nothing shippable is affected.

## 3. author_credit

Fields that cannot be printed as a credit line as they stand. The blocking cases are the
**7 CC BY rows with no author at all** - CC BY requires attribution, so those images must
not go on the website until a name is recovered.
