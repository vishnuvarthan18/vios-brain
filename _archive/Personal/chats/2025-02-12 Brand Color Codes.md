# Installing n8n on macOS: Step-by-Step Guide

## Prerequisites
- macOS (your Mac operating system)
- Terminal app
- Internet connection

## Option 1: Installing with Docker (Recommended)

### Step 1: Install Docker Desktop for Mac
1. Download Docker Desktop from [Docker's official website](https://www.docker.com/products/docker-desktop)
2. Open the downloaded .dmg file
3. Drag Docker to your Applications folder
4. Open Docker from your Applications folder
5. Wait for Docker to start (you'll see the Docker icon in your menu bar)

### Step 2: Run n8n using Docker
1. Open Terminal (from Applications > Utilities > Terminal)
2. Run this command:
```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8n/n8n
```
3. Wait for n8n to start up
4. Access n8n in your browser at: http://localhost:5678

## Option 2: Installing with npm

### Step 1: Install Node.js and npm
1. Download the LTS version of Node.js from [nodejs.org](https://nodejs.org/)
2. Open the downloaded .pkg file and follow installation prompts
3. Verify installation by opening Terminal and running:
```bash
node -v
npm -v
```

### Step 2: Install n8n globally
1. In Terminal, run:
```bash
npm install -g n8n
```
2. Wait for installation to complete

### Step 3: Start n8n
1. In Terminal, run:
```bash
n8n start
```
2. Access n8n in your browser at: http://localhost:5678

## Getting Started After Installation
1. Create an account in the n8n interface
2. Start building your first workflow
3. Add and configure nodes
4. Save and activate your workflow

## Maintenance Tips
- Update n8n regularly:
  - Docker: `docker pull n8n/n8n:latest`
  - npm: `npm update -g n8n`
- Back up your workflows (stored in ~/.n8n by default)
- Monitor resource usage on your Mac

## Troubleshooting Common Issues
- Port conflicts: Change the port using `-p <new-port>:5678` in Docker or `n8n start --port <new-port>` with npm
- Permission issues: Use `sudo` for npm installation if needed
- Memory errors: Close other applications to free resources
