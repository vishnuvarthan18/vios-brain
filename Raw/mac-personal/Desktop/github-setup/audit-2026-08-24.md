## How to read this

**Missing** counts expected paths absent from the repo. A high number on a
small or old project is not a problem to fix — it is a project the
conventions were never applied to. Judge by whether you still work in it.

**Commit format** is the share of the last 30 commit subjects matching
`<type>: <lowercase imperative>`. This is the one convention worth
backfilling attention on, because release tooling reads it. History
already written cannot be fixed without rewriting it — do not. What
matters is the next commit.

**Verdict** is a rough sort, not an instruction:

- *close* — a couple of files away, worth doing now
- *worth fixing* — a session's work
- *large gap* — decide whether the project deserves it before spending the time
- *skip* — fork or archived

## What this audit did not check

- **File headers.** Checking SPDX headers means reading every source file
  in every repo. Left out deliberately.
- **README shape.** Whether a README leads with the project and links back
  to the conventions is a judgement call, not a grep.
- **Naming.** param-case files, snake_case keys — needs reading the code.
- **Deployment wiring.** Nothing here knows what is deployed from where.
