Semmozhi Brahmi 2.0
===================
An original, hand-built monoline font for the Unicode Brahmi block (U+11000-1107F), including the
Old Tamil letters (zha, rra, nnna, lla), Old Tamil short e and o, the Old Tamil pulli, and Brahmi numerals.
The letters are redrawn as thin single-line pen strokes. Their centre-lines follow the letter structures of
Noto Sans Brahmi (Copyright 2022 The Noto Project Authors, SIL OFL 1.1), so the shapes match the standard letters.

Licence: SIL Open Font License 1.1 (see OFL.txt). Free for personal, commercial and print use.
You may share it and change it. You may not sell the font by itself.

Status: version 2.0 is a first release. An automatic check shows about 99% agreement with the reference letter structure.
This is not a check against inscriptions and has not been reviewed by an epigraphy expert.
Please do not use it as an evidence-grade reproduction of a specific inscription.

Install: macOS - double-click the .ttf, click Install Font. Windows - right-click, Install.
Linux - copy to ~/.fonts and run fc-cache -f.
Web:
@font-face{font-family:"Semmozhi Brahmi";src:url(SemmozhiBrahmi-Regular.woff2) format("woff2"),url(SemmozhiBrahmi-Regular.woff) format("woff"),url(SemmozhiBrahmi-Regular.ttf) format("truetype");font-display:swap}
