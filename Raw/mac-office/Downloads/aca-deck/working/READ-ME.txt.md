araCreate deck - working folder
==============================

For each day there is a folder: day-5, day-6, day-7, day-8, day-9

Inside each one:

  standalone-day-N.html   <- the "Save as standalone HTML" download
  images/                 <- the pictures for that day

STEPS FOR ONE DAY
-----------------
1. In Claude Design, open that day
2. Save as standalone HTML, download it
3. Put it in the day folder, named standalone-day-N.html
4. Put any pictures into that day's images/ folder
   (open PUT-PICTURES-HERE.txt to see the names)
5. Tell Claude: "day N ready"

DO NOT drag pictures into Claude Design.
That save is broken right now - they vanish on refresh.
Put them in the images/ folder instead.
