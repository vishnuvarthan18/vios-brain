Primary call-to-action button — square-cornered, uppercase, wide letter-spacing, lifts up on hover (the araCreate CTA signature).

```jsx
<Button variant="primary">Let's Talk About Your Idea</Button>
<Button variant="secondary" size="lg">View Projects</Button>
<Button variant="ghost">Learn More</Button>
<Button variant="link">See all</Button>
```

Variants: `primary` (Golden Sun fill, graphite text), `secondary` (graphite fill → yellow on hover), `ghost` (hairline border), `link` (underlined inline). Sizes: `sm` / `md` / `lg`. Use `iconLeft` / `iconRight` for arrows. Buttons are always square — never round the corners.
