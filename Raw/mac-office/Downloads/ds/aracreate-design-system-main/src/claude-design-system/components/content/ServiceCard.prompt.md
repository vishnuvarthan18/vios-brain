The araCreate service/vertical tile — isometric icon, title in Poppins, short blurb, and a "Learn more" link that brightens on hover.

```jsx
<ServiceCard
  icon="assets/icons/icon-product-design.svg"
  number="01"
  title="Engineering"
  description="Hardware and software technologies, designed and built from mind to market."
/>
```

Use the icons in `assets/icons/` (isometric line style). Lay several out in a responsive grid for a services section.
