AND Gate using Two push Buttons and Three LEDs

Aim

To design and implement an AND gate circuit using two push buttons as inputs and three
LEDs on a breadboard, and verify the logical AND operation.

Problem Statement

In digital electronics, an AND gate produces an output only when all inputs are HIGH (ON).
The objective is to demonstrate the working of an AND gate using simple electronic
components such as LEDs, push buttons, a resistor, and connecting wires.

Proposed Solution

Two push buttons are used as input switches (A and B). Three LEDs indicate the status of
the inputs and output:

   ●​ LED 1 → Input A indication
   ●​ LED 2 → Input B indication
   ●​ LED 3 → Output indication

The output LED glows only when both push buttons are pressed simultaneously,
demonstrating the AND gate truth table.

Components Required

   ●​   Breadboard
   ●​   3 LEDs
   ●​   2 Push Buttons
   ●​   1 Resistor
   ●​   Connecting Wires
   ●​   9V Battery / 5V Power Supply

Circuit Working

   ●​ When Push Button A is pressed, LED 1 glows.
   ●​ When Push Button B is pressed, LED 2 glows.
   ●​ If only one button is pressed, the output LED remains OFF.
   ●​ When both Push Button A and Push Button B are pressed together, current flows
      through the output path and the output LED glows.
   ●​ Thus, the circuit behaves exactly like an AND gate.



Truth Table
Input A     Input B   Output LED

  0            0         OFF

  0            1         OFF

  1            0         OFF

  1            1         ON



Procedure

   1.​ Place the two push buttons and three LEDs on the breadboard.
   2.​ Connect the positive terminal of the battery to the push buttons.
   3.​ Connect LED 1 and LED 2 to indicate Input A and Input B.
   4.​ Connect the output LED through the resistor.
   5.​ Complete all connections using jumper wires.
   6.​ Power the circuit using a battery.
   7.​ Press the buttons individually and then together.
   8.​ Observe the LEDs and verify the AND gate operation.

Applications

   ●​     Digital logic demonstrations
   ●​     Electronic learning kits
   ●​     Industrial control systems
   ●​     Security systems
   ●​     Automation circuits
   ●​     Digital computers and microcontrollers

Advantages

   ●​     Simple and low-cost circuit
   ●​     Easy to understand digital logic
   ●​     Requires fewer components
   ●​     Suitable for beginners
   ●​     Portable and reliable


Result

The designed circuit successfully performs the AND gate operation. The output LED glows
only when both push buttons are pressed simultaneously.
Conclusion

The AND gate circuit was implemented successfully using two push buttons, three LEDs, a
resistor, and a breadboard. The output followed the AND gate truth table, proving the correct
operation of the circuit.
