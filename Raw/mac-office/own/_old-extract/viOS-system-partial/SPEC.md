# viOS — build spec (shared contract for all builders)

Owner: Vishnu (araCreate Group). Style for all user-facing text: short, points, simple English.
Everything must be open source (OSI licenses). Date: 2026-09-30.

## Goal
viOS = Vishnu's personal AI operating system, reachable from anywhere (web, phone, Telegram/WhatsApp,
any AI app via remote MCP, terminal agents), connected to all AI models through one gateway, with one
data vault (plain Markdown + Git) that any AI can read and continue work from.
Core engine on the Mac: **LifeOS** (github.com/danielmiessler/LifeOS, MIT — cloned at /root/up/Personal_AI_Infrastructure).

## Vault (read /root/vios/vault-template/AGENTS.md first)
- `core/` — CORE, USER, GOALS, VALUES, RULES. Human-written. **AI/API: read-only.**
- `ai/` — AI read/write: INDEX.md, inbox/INBOX.md, daily/YYYY-MM-DD.md, projects/<name>/{README,STATE,LOG,DECISIONS}.md,
  tasks/ (Backlog.md format), agents/*.md + REGISTRY.md, people/, life/, knowledge/raw (read-only for AI), knowledge/wiki, notes/, logs/, archive/.
- **Private zone never exists on the server.** Any path containing a `private` / `viOS-Private` segment is refused.
- Notes have YAML frontmatter + `## For future agent` preamble. Templates in `vault-template/templates/`.
- Tasks: Backlog.md files `ai/tasks/tasks/vi-<N> - <Title-Slug>.md`, frontmatter: id: VI-N, title, status ("To Do"|"In Progress"|"Done"),
  assignee: [], created_date: 'YYYY-MM-DD HH:MM', labels: [project], dependencies: [], priority: high|medium|low. Config: `backlog.config.yml` (task_prefix vi, backlog_directory ai/tasks).
- Existing Python helpers you may import/reuse: `vault-template/tools/vios_lib.py` (frontmatter parser), `dashboard.py`, `doctor.py`, `new_project.py`.

## vios-api contract (builder A implements; B and C consume)
Base: `http://vios-api:8080`. JSON. Auth: (secret removed) `Remote-User` (set by Caddy/Authelia; trusted only from the Docker network) or `Authorization: Bearer <VIOS_API_TOKEN>`.
REST:
- `GET /api/health` → `{ok, vault, git: {head, dirty, last_sync}}` (no auth)
- `GET /api/dashboard` → `{date, focus[], projects[{name,status,as_of,age_days,next,blockers[]}], tasks{status:[task]}, agents[], inbox[]}`
- `GET /api/projects` · `GET /api/projects/{name}` → `{name, readme, state, log_tail, decisions}` · `POST /api/projects {name, what, repo}`
- `POST /api/projects/{name}/handoff {agent, did, verified, surprises, now[], next[], blockers[]}` → updates STATE.md, appends LOG.md, adds daily line, commits
- `GET /api/tasks?project=&status=` · `POST /api/tasks {title, project, priority, description}` · `PATCH /api/tasks/{id} {status?, title?, priority?}`
- `POST /api/capture {text, kind: auto|task|note|link, project?}` → files to inbox / task / raw link, returns `{saved_to}`
- `GET /api/search?q=&limit=` → `[{path, title, snippet, score}]` (SQLite FTS5 over ai/ + core/, rebuilt on change)
- `GET /api/notes?path=` → `{path, meta, body, writable}` · `PUT /api/notes {path, content}` (ai/ only; never core/, never knowledge/raw existing files)
- `GET /api/daily/today` (creates from template if missing) · `GET /api/agents`
MCP (streamable HTTP at `/mcp`): tools `vios_resume(project)`, `vios_handoff(...)`, `vios_capture(text, kind, project)`, `vios_search(query, limit)`,
`vios_read(path)`, `vios_write(path, content)`, `vios_list(dir)`, `vios_tasks(project, status)`, `vios_task_create(...)`, `vios_task_update(id, ...)`,
`vios_today()`, `vios_project_create(name, what, repo)`, `vios_dashboard()`. Server instructions string explains the zones + resume/handoff protocol.
MCP auth: (1) bearer `VIOS_API_TOKEN` (LibreChat, Hermes, Claude Code, Cursor); (2) OAuth 2.1 for Claude.ai / ChatGPT connectors via FastMCP OIDC proxy to Authelia
(`https://auth.$VIOS_DOMAIN`, client id `vios-mcp`, secret `VIOS_OIDC_CLIENT_SECRET`, allowed user `vishnu`). If the OAuth proxy is not configured, bearer only.
Sync: background loop every `VIOS_SYNC_INTERVAL` s: `git add -A`, commit `vios-sync: <n> files [agent:<who>]` if dirty, `git pull --rebase` and `git push` to `origin` if set. Conflicts → keep both, write a note to ai/inbox, never lose data.
Every write is a git commit with author `viOS <vios@localhost>` and trailer `Agent: <client>`.

## Testing constraints (important)
- Docker daemon runs here but **Docker Hub / ghcr / quay are blocked** — you cannot pull images. Validate compose with `docker compose config` only.
- Allowed: pypi, npm, GitHub (incl. release downloads), most websites. Test natively (install binaries/packages, run them).
- Scratch space: `/tmp/<yourname>`. Do not modify other builders' folders. Do not modify vault-template except where told.

## Quality bar
Production-grade: idempotent scripts (`set -euo pipefail`), pinned versions, healthchecks, restart policies, resource limits, no secrets in git,
least privilege (Rule of Two), clear errors. Write tests where it makes sense and run them. Report exactly what you tested and what you could not.
