  Meesho's weekly retention among Tier 3+ users is just 25%.

  That means 3 out of 4 users never return the following week.

  This isn't a growth problem. This is a retention crisis that's bleeding money.

We acquired aggressively. But those users drop off within 2-4 weeks. And they tell their friends
the platform doesn't work for them. That's negative word-of-mouth we can't buy back.

SOLUTION #1
TRUST BADGE
    Problem      "Is this seller real? Will I get a fake product?"

                 Verify sellers based on real performance.
                    Fulfillment rate >80%
    Solution
                    Return rate <5%
                    Customer rating 4.0+

                    Removes biggest fear
  Why It Works      Drives repeat purchases
                    Creates positive spiral (verified → more sales → better quality)


Impact: Repeat purchase rate +35%
SOLUTION #2
REGIONAL LANGUAGE
    Problem      "This app doesn't feel built for me."

                 Build the app in Hindi, Marathi, Tamil first.
                    UI in regional language
    Solution
                    Product descriptions localized
                    Local payment partners

                    Removes language friction
  Why It Works      Psychological shift ("This is for me")
                    Competitive advantage (others haven't done this)


Impact: Regional user retention +25%
