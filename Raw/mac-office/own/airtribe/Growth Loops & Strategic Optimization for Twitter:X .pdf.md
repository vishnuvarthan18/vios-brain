Growth Loop
                                                 Viral Content Loop

Loop Type: Viral
Trigger: User posts engaging public content
Action: Audience interacts—retweet/shares/engages
Reward: Increased followers, visibility—shown in trending/For You
Re-engagement: Notifications and virality prompt users to return
Growth Loop
                                           Rich Media Engagement Loop

Loop Type: Content/Engagement
Trigger: User tweets video, image, or GIF
Action: Media attracts likes/comments/shares, especially video
Reward: Algorithm surfaces to wider audience, profile visits, organic follower growth
Re-engagement: Video replays, notifications, Space invites
Growth Loop
                                           Spaces & Community Loop

Loop Type: Viral/Content
Trigger: User hosts/joins a Space
Action: Real-time voice & chat; community participation grows
Reward: New followers, live Q&A
Re-engagement: Notifications for Spaces, community revisits
Growth Loop
                                                 Paid Boost Loop

Loop Type: Paid/Promoted
Trigger: User/brand boosts/post
Action: Amplified distribution → targeted users
Reward: New followers, leads, or sales
Re-engagement: Retargeting via more ads, follow-up content
Growth Loop
                                                Reactivation Loop

Loop Type: Re-engagement
Trigger: Inactive user triggers automated DM/email
Action: Receives personalized notification
Reward: New session, rediscovery
Re-engagement: Cycle repeats with touchpoints (trends, direct DMs)
Rich Media Engagement Loop
Chosen for analysis due to its current dominance in user engagement
