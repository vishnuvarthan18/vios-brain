# halle-feedback-widget

## What
- Feedback widget + admin dashboard for B. Halle website testing (apps.b-halle.de)

## Why
- Elderly, non-technical B. Halle testers (10–30, German-speaking, 49 pages) report website problems in plain words; the team works each report to a resolution and exports sign-off evidence.

## Definition of done
- Live on apps.b-halle.de, testers can report from the Webflow site, staff work the queue, client signs off from the CSV export.
- Old IONOS M+ server cancelled after a clean migration.
