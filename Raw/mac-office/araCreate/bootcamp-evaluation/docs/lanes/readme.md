# Lane reports

One file per lane. Each lane writes only its own, which is why these never
conflict.

- `lane-a.md` — daily staff screens
- `lane-b.md` — opening work and the quiz side
- `lane-c.md` — surveys, assessment, projects
- `lane-d.md` — people and reports

Each records, per screen: the **check list** (what Vishnu clicks to prove it
works), anything from the old screen that could not be reproduced, and anything
shared the lane needed and had to work around.

Nobody ticks `docs/v3-ui-migration.md` during lane work. It is ticked once, at
the end, when the lanes are merged.
