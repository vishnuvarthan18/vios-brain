# OBSERVABILITY

Config for the platform's observability stack (Prometheus, Grafana, Loki, Alloy, Tempo — run as containers in `docker-compose.yml`, not defined here). `prometheus.prod.yml` (scrape config), `loki-config.yml` / `tempo.yml` (log/trace storage), `alloy/config.prod.alloy` (River syntax — tails Docker container logs into Loki, forwards OTLP traces to Tempo), `grafana/datasources-prod/` (datasource wiring), `grafana/provisioning/` (dashboard-loader + alerting), `grafana/dashboards/*.json` (versioned as code — edit the JSON, not the Grafana UI). The one thing here with a public path is Alloy: `Caddyfile.prod` strips `/faro-collector/*` on `SITE_DOMAIN` and proxies it to the Faro receiver Alloy listens on at port 12347, which is how browser telemetry arrives (`FARO_CORS_ORIGIN` bounds the origins it accepts). Grafana no longer has one — `Caddyfile.prod` carries no `grafana.arametrics.app` site block, and neither it nor the `forward_auth` gate that used to front it still exists; that file's closing comment records why, and why `GRAFANA_DOMAIN` is still required (it feeds this stack's own `GF_SERVER_ROOT_URL`). Nothing in the block publishes a host port, and Grafana is gated by its own login only — anonymous access off, no SSO, no second factor.

The stack runs on the server only — local dev starts no observability containers, so any change here is first exercised on the server.
