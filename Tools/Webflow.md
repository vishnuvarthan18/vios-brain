# Webflow
- Website builder and hosting used by araCreate for client sites.
- Hosts aracreate.group (built from the Duotint template).
- Export ZIP leaves CMS content empty; forms, search and password pages do not work outside Webflow.
- aracreate.group template project is on the Starter plan, so no code export; the published demo was crawled instead.
- B. Halle site (b-halle.de, staging halle-dev.webflow.io) built in Webflow; Style Guide page with "Design Tokens" variables.
- theregenroom.co.uk hosted on Webflow (CMS Hosting plan, 50GB monthly bandwidth).
- Claude works with it through the Webflow connector.
