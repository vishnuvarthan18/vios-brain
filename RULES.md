# Rules for every AI

1. Start: read RULES, About me, Goals. For project work also read Projects/<name>/STATE.md.
2. Never change "About me" or "Goals" unless Vishnu asks.
3. New ideas and quick notes go to Inbox/ (one file each, name: YYYY-MM-DD short-title.md).
4. Each project has a folder Projects/<name>/ with:
   - STATE.md: where we are, next steps
   - LOG.md: dated entries, newest on top
5. End of any work: update the project STATE.md, add a line to its LOG.md, and add a line to Daily log/YYYY-MM-DD.md.
6. Never delete files. Move old things to Archive/.
7. Write in simple English, short points.
8. Never save passwords or secret keys here.
9. Private things (IDs, bank, loans, property, family, health, contacts list) never go in this brain. They live in the private box `~/vios/private/` on the server, which AIs do not read.
10. Update pages in place. Do not add "## Added ..." blocks at the bottom. Keep one clean version; newest facts win.
11. One question list only: Inbox/Questions for Vishnu.md. LOG.md newest on top.
12. Home pages (index.md and Projects.md) are rebuilt automatically every hour from project pages. Keep `status:` correct in SUMMARY and STATE (active / idea / paused / done).
